# SAAS-VEICULOS

Sistema de gestão para loja de **fiado, locação e venda de veículos**, com login para você
e seus funcionários. Construído em HTML/CSS/JS puro no frontend e **Supabase** (Postgres +
Auth + Row Level Security) como backend, versionado no **GitHub**.

## Como esta pasta está organizada

```
SAAS-VEICULOS/
├── CURRENT/        → sempre o projeto completo da versão mais recente (é o que você usa/publica)
├── VERSIONS/       → cópia congelada de cada versão entregue (v0.1, v0.2, ...)
├── docs/
│   └── CHANGELOG.md → histórico de tudo que mudou, versão por versão
└── README.md        → este arquivo
```

**Regra de uso:** trabalhe sempre a partir de `CURRENT/`. As pastas em `VERSIONS/` são só
histórico — não precisa mexer nelas.
